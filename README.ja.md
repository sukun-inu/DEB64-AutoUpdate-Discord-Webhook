# DEB64-AutoUpdate-Discord-Webhook

Linux サーバーの更新を自動で当てて、結果を Discord に知らせる仕組みです。

サーバーは放っておくとセキュリティ更新が溜まっていきます。かといって毎日ログインして
確認するのも続きません。これを入れておくと**更新は毎日勝手に当たり、その結果だけが
Discord に流れてきます**。通知のタイトルに「サーバー名 ｜ 結果」が出るので、
チャンネルを眺めるだけで状態が分かります。

更新の内容によっては再起動が必要になりますが、その場では再起動しません。
**あなたが決めた時刻（深夜など）に予約**され、再起動の直前にバックアップの実行中などでないかを確かめてから再起動します。

English: [README.md](README.md)

## できること

- 毎日決まった時刻に自動でパッケージ更新（`unattended-upgrades`）
- 更新したパッケージを「旧バージョン → 新バージョン」で通知
- 再起動が要る更新のときだけ、指定時刻に再起動を予約（予約時刻と、どのパッケージのせいかも通知）
- 再起動の直前に、バックアップの実行中・PVE クラスタの停止ノードを確認し、危なければ待つ／見送る
- **再起動したら「再起動完了」を通知**。予約外の起動（停電・手動再起動）も分かる
- 自動更新の対象外で残っている更新（PVE のパッケージなど）は、増えた分だけを通知
- 毎週月曜に「安定性チェック」を通知（ディスク・メモリ・負荷・失敗中のサービス・時刻同期・前回のメンテナンス結果など）
- スクリプトが途中で止まっても、エラーとして通知

## 届く通知

| タイトルの例 | いつ |
|---|---|
| ✅ pve-01 ｜ 3 件更新 | 毎日のメンテナンス（問題なし） |
| 🔁 pve-01 ｜ 3 件更新 ・ 11/07 07:00 に再起動 | 毎日のメンテナンスで、再起動を予約した |
| ⚠️ pve-01 ｜ 更新なし（要確認） | 毎日のメンテナンスで、失敗中のサービスやディスク不足があった |
| ❌ pve-01 ｜ メンテナンス失敗 | 更新や再起動の予約に失敗した |
| 🔁 pve-01 ｜ これから再起動します | 予約した再起動の直前 |
| ⛔ pve-01 ｜ 再起動を見送り | 再起動の直前の確認で危ないと判断した（翌日に予約し直す） |
| 🟢 pve-01 ｜ 再起動完了 | 予約した再起動のあと、起動して 90 秒後 |
| 🔵 pve-01 ｜ 起動しました（予約外） | 手動再起動・停電などで起動した |
| 🩺 pve-01 ｜ 安定性チェック：問題なし | 毎週月曜 09:00 |
| ❌ pve-01 ｜ スクリプトエラー | スクリプトが途中で異常終了した |

「これから再起動します」が来たのに「再起動完了」が来なければ、そのサーバーは上がってきていません。

## 動作環境

- systemd を使う Debian 系の OS（Debian 12 / 13、Ubuntu 24.04 以降、Proxmox VE、Proxmox Backup Server で使っています）
- root 権限（root で実行するか sudo）
- Discord の Webhook URL

## クイックスタート

### インストール

```bash
curl -fsSL https://raw.githubusercontent.com/sukun-inu/DEB64-AutoUpdate-Discord-Webhook/main/install.sh | sudo bash
```

> 実行前にスクリプトの内容を確認したい場合:
> ```bash
> curl -fsSL https://raw.githubusercontent.com/sukun-inu/DEB64-AutoUpdate-Discord-Webhook/main/install.sh | less
> ```

インストール中に以下を対話形式で入力します:
- **Webhook URL** — Discord チャンネルの「サーバー設定 → 連携サービス → ウェブフック」から取得
- **メンテナンス実行時刻** — 更新を実行する時刻（デフォルト: `02:30`）
- **再起動時刻** — 再起動が必要な更新があったとき、次にこの時刻が来たら再起動（デフォルト: `03:00`。02:30 の更新で必要になれば 30 分後）

タイムゾーンが Asia/Tokyo でなければ変更するか聞かれます。時刻同期（NTP）が無効なら有効にします。
最後にテスト通知を送るか聞かれるので、送って Discord に届くことを確認してください。

### 更新・設定の変更

同じコマンドをもう一度実行すると、スクリプトが最新版に置き換わります。
既存の設定を読み込むので、変えない項目は空のまま Enter で引き継げます。時刻を変えたいときもこの方法が簡単です。

### アンインストール

```bash
curl -fsSL https://raw.githubusercontent.com/sukun-inu/DEB64-AutoUpdate-Discord-Webhook/main/uninstall.sh | sudo bash
```

インストール済みファイルを検出して一覧表示し、削除確認を求めます。予約中の再起動があれば取り消します。
ログファイルの削除有無も個別に確認します。
